# Susanin — метки на карте

Мобильное приложение на React Native + Expo для создания геометок на карте с возможностью прикреплять к ним фотографии из галереи и получать уведомления при приближении к сохранённым местам. Все данные хранятся локально в базе данных SQLite.

## Возможности
- **Карта**: полноэкранная интерактивная карта (MapLibre GL в WebView для Android, react-native-maps для iOS).
- **Метки**: добавление долгим нажатием, просмотр деталей, переименование и удаление.
- **Фотографии**: прикрепление нескольких изображений из галереи к каждой метке, удаление.
- **Геолокация**: отслеживание текущего местоположения пользователя в реальном времени.
- **Уведомления**: локальные уведомления «Вы рядом с меткой!» при приближении к сохранённым точкам.
- **База данных**: локальное хранение в SQLite с миграциями и каскадным удалением.

## Технологии
- **Expo** (managed workflow), **React Native**, **TypeScript**
- **Expo Router** — файловая навигация (tabs + stack)
- **expo-sqlite** — локальная база данных
- **expo-image-picker** — выбор изображений
- **expo-location** — геолокация
- **expo-notifications** — локальные уведомления
- **react-native-webview + MapLibre GL JS** — карта на Android
- **react-native-maps** — карта на iOS
- **patch-package** — патч для совместимости `expo-notifications` с Expo Go на Android

## Установка и запуск

### Требования
- Node.js LTS, npm (или yarn)
- Приложение **Expo Go** на телефоне (Android / iOS) *или* эмулятор/симулятор

### Шаги
```bash
# 1. Клонировать репозиторий
git clone https://github.com/TiredOptimist/susanin.git
cd susanin

# 2. Установить зависимости (патч применится автоматически)
npm install

# 3. Запустить dev-сервер Expo
npx expo start
